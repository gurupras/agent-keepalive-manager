agent-keepalive

Keeps the prompt caches of your Claude Code and Codex CLI sessions warm while you step away.

Install All downloads Source on GitHub Usage dashboard

What it does

  • A local server with a web UI finds the Claude Code and Codex sessions running on your machine. It only reads; it never types into them.
  • For the sessions you pick, it sends a short ping just before the provider's prompt cache expires, so coming back to a long conversation reads the cache instead of rewriting it.
  • A ledger shows what the pings cost and what they saved, and the UI tells you when a ping is not worth it.
  • It reports pseudonymous daily usage totals to the public hub. You can turn that off in one click, and the reports never contain prompts, paths, names or session ids.

Install

Debian, Ubuntu

curl -fsSL https://agent-keepalive.gurupras.me/download/repo/agent-keepalive-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/agent-keepalive-archive-keyring.gpg >/dev/null
curl -fsSL https://agent-keepalive.gurupras.me/download/repo/agent-keepalive.sources \
  | sudo tee /etc/apt/sources.list.d/agent-keepalive.sources >/dev/null
sudo apt update && sudo apt install agent-keepalive

Fedora, RHEL, openSUSE

sudo curl -fsSL -o /etc/yum.repos.d/agent-keepalive.repo \
  https://agent-keepalive.gurupras.me/download/repo/agent-keepalive.repo
sudo dnf install agent-keepalive

Arch Linux

curl -fsSL -o /tmp/agent-keepalive.asc \
  https://agent-keepalive.gurupras.me/download/repo/agent-keepalive-archive-keyring.asc
sudo pacman-key --add /tmp/agent-keepalive.asc
sudo pacman-key --lsign-key "$(curl -fsSL https://agent-keepalive.gurupras.me/download/repo/FINGERPRINT)"
curl -fsSL https://agent-keepalive.gurupras.me/download/repo/pacman.conf \
  | sudo tee -a /etc/pacman.conf >/dev/null
sudo pacman -Sy agent-keepalive

macOS and Linux with Homebrew

brew install gurupras/tap/agent-keepalive

Or the .pkg installer from downloads, which adds an app to Applications.

Windows

Download agent-keepalive-…-setup-x64.exe (or arm64) from downloads. It installs for your user only and needs no administrator rights. A portable .exe is there too.

Any Linux, no install

The .AppImage in downloads: make it executable and run it. It updates itself.

Installing a .deb, .rpm or Arch package from the downloads page registers the same signed repository, so your package manager keeps it up to date. Each release folder has a SHA256SUMS file.

Quick start

agent-keepalive open

This starts the server in the background if it is not running and opens the UI in your browser. Pick a session, choose how long to keep it warm, and leave. The menu has Quit to stop the server.

Usage reports

The public build sends one small report per day: counts of sessions, pings and their outcomes, and the dollar amounts saved and spent, tagged with a random install id. Turn it off in Settings › Usage reports, with agent-keepalive metrics off, or with AGENT_KEEPALIVE_METRICS=off. Exactly what is sent.
